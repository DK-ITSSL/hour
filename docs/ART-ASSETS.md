# 캐릭터·애셋 그림 교체 가이드

퀘스트와 애셋은 게임 디자인 단계에서 다시 정한다. 그 전까지 앱은 코드로 그린 **임시 그림**을 쓴다. 실제 그림 파일을 아래 규칙대로 넣으면 **코드를 고치지 않고** 그 파일로 바뀐다. 파일이 없는 항목은 계속 임시 그림을 쓴다.

## 파일 위치와 이름

`app/src/main/assets/art/` 아래에 둔다.

| 파일 | 용도 | 권장 규격 |
|---|---|---|
| `character/base.png` | 기본 캐릭터 '아워'(가칭) | 1024×1024, 투명 배경, 캐릭터가 아래쪽 중앙에 서 있게 |
| `layer/<규칙 id>.png` | 캐릭터 위에 겹치는 착용 레이어 | `base.png`와 **같은 크기·같은 위치 기준**, 투명 배경 |
| `icon/<규칙 id>.png` | 옷장 타일·도착 선물 카드 아이콘 | 512×512, 투명 배경, 여백 10% |

- `<규칙 id>`는 `domain/src/main/resources/unlock_rules.json`의 `id`다. 예: `layer/trip_raincoat.png`, `icon/trip_raincoat.png`
- 잠긴 애셋은 아이콘을 회색 실루엣으로 칠해서 보여준다. 따로 그릴 필요 없다.
- 방(ROOM) 슬롯 애셋은 레이어가 아니라 **아이콘 그림**을 방 오른쪽 선반에 진열한다.

## 겹치는 순서

방 배경 → 방 소품(선반) → 몸 → 옷(OUTFIT) → 소품(ACCESSORY) → 모자(HAT)

임시 그림에서는 망토만 몸 뒤에 그린다. 실제 레이어 파일은 위 순서로 겹치므로, 몸 뒤로 보여야 하는 부분(망토 자락 등)은 몸 바깥쪽만 그리면 된다.

## 안전 원칙(규칙을 새로 만들 때)

- 위험 행동의 **발생**(속도, 급제동, 주행 시간, 야간·빗길 누적)은 조건으로 쓸 수 없다. 로더가 걸러 낸다.
- 위험 행동이 **없었던 것**은 보상할 수 있다(안심 보상: `CLEAN_JOURNEY`, `CLEAN_STREAK`).
- 누적 거리 조건은 바람(창문)만 허용한다.
